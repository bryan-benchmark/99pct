# Why now — The Coordination Problem

**Status:** Proposed  
**Maturity:** Proposed  
**Not Canonical.**  
**Site essay:** `/why-now`

As organizations become more capable, misalignment becomes more expensive. Missionism is an attempt to make alignment structural rather than managerial.

Compressed proposition:

> **AI makes intelligence less scarce. Missionism is an experiment in making alignment less scarce.**

Design constraint:

> Every rule Missionism adds should remove more coordination complexity than it creates.

Full public essay lives on the website. This file marks the proposal in the corpus so provenance and maturity stay honest.
