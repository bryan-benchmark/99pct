# Bicameral mission representation

**Status:** Proposed  
**Version:** Missionism adjacent — not canonical  
**Last updated:** September 2026  
**Maturity:** Proposed (mechanism)

## Problem

Federations of missions need representation without:

- giant missions controlling everything, or
- tiny missions having disproportionate control.

## Sketch

```text
CONTRIBUTOR REPRESENTATION
Power based on contribution / ownership / value created

+

MISSION REPRESENTATION
Recognized missions receive independent representation

↓

Certain major decisions require agreement from both
```

## Status

This is **not** part of Missionism Core v0.1.

It is a preferred direction for experimentation. Implementations may test it. The detailed mechanism remains **Open**. Related questions live on the public Open Questions page.

Do not present this as a constitutional requirement.
