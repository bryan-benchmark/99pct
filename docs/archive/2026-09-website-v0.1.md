# Archived public page narratives — September 2026

Prior to Missionism website v0.1, the Next.js app exposed long-form doctrine pages that largely restated `/spec` and `/docs`. Those **routes** were retired in favor of a minimal public IA.

## What was removed from the public tree

| Former route | Nearest v0.1 page |
|--------------|-------------------|
| `/system`, `/protocol` | `/how-it-works` |
| `/compact`, `/constitution`, `/globals` | `/principles` |
| `/ownership`, `/mcu`, `/mechanisms`, `/operating`, `/meta`, `/lexicon` | `/specification` |
| `/mishys` | https://mishys.com |
| `/missions/*` | `/how-it-works` (worked example) |

## Where the substance lives now

- Canonical lean surface: `spec/canonical.json`, `CORE.md`, …
- Pre-0.1 constitution: `docs/archive/CONSTITUTION_v1_DRAFT.md` (stub at `spec/CONSTITUTION.md`)
- Deep protocol: remaining `spec/*.md`
- Public narratives: `docs/BUILD_THE_NEXT_ERA.md`, `docs/MISSIONISM.md`, ownership docs, etc.

## Why archive instead of erase

Missionism should retain unusually good provenance. Prefer git history + this note over destroying intellectual structure when the public UI shrinks.
