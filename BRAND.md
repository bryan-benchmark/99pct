# Brand

## Lockup

The Missionism mark + wordmark are **proprietary custom vectors**, not a licensed typeface.

| Asset | Path | Use |
| --- | --- | --- |
| Icon SVG | `public/missionism_icon_vector.svg` | Favicon, nav, hero, footer |
| Wordmark SVG | `public/missionism_wordmark_vector.svg` | Nav, hero, footer (includes green **M** notches) |
| Full lockup PNG | `public/logo-text.png` | Press / fallback raster |
| Icon PNG (dark) | `public/logo.png` | Apple touch / dark contexts |
| Source packs | `brand/*.zip`, `brand/*.pdf` | Archive only — not served |

Do not recreate the wordmark from a stock font and call it final.

## Wordmark type (design history)

Closest real matches for *reference only* when refining vectors: Microgramma D Extended Bold, Eurostile Extended Bold. Free approximations (Michroma, Orbitron, Bank Gothic) are for mocks only — live UI uses the SVG wordmark.
