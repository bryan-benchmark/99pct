# Value

**Status:** Draft  
**Version:** 0.1  
**Last updated:** September 2026  
**Maturity:** Canonical (requirements) · measurement methods mostly Open

## Canonical requirements

- The mission must define what “better” means in durable directional terms.
- Organizations should distinguish **mission value** from mere financial extraction.
- Rules for recognizing contribution should be **prospective and transparent** where possible—not rewritten after the fact to strip contributors.

## Open

- How to measure value in each domain
- How to weigh learning, negative results, and infrastructure work
- Cross-mission value comparison
