# Collaboration

Don’t fight over the pie until you’ve tried to make the pie bigger.

Missionism is positive-sum. Seek solutions where the Mission advances and contributors become better off.

Major disputes require a **Positive-Sum Search** before tradeoff adjudication: steelman → shared parent Mission → conflicting variables → search for mutual gain → experiment if empirical → explicit tradeoff → lowest competent decide → record dissent → revisit when assumptions change.
