## Kernel (one paragraph)

Public signed mission contracts → deterministic MCU issuance → separate perpetual pies → append-only transparency log → periodic Bitcoin timestamp → independent verification.

Bitcoin is a notary, not a database. MCU is not a token. MCU is a **global contribution denomination** and a **mission-local ownership claim** — not an exchange rate across pies. Pay locally; own globally. Collaboration allocations must be pre-agreed and public.
