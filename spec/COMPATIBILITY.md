# Compatibility

**Missionism Protocol v0.1 · Draft · September 2026**  
**Maturity:** Canonical (definition) · certification process evolving

## Missionism-compatible (v0.1)

An implementation may claim compatibility with Missionism **v0.1** only if it:

1. Publishes a measurable mission and version of the rules it follows (see claim `measurableMission` in [`canonical.json`](./canonical.json)).
2. Respects [`RIGHTS_AND_CONSTRAINTS.md`](./RIGHTS_AND_CONSTRAINTS.md) and claims `humansNotVariables`, `voluntaryAdoption`.
3. Satisfies claim `contributorPath` (instrument may vary).
4. Does not present Proposed or Experimental mechanisms as if they were Canonical requirements.
5. Does not claim the Missionism name for a fork that rejects the canonical version without clear labeling (claim `forkability`).

## Certification

Certification, when used, is about **inspectable commitments** (e.g. public `/mission`), not moral approval. See [CERTIFICATION.md](./CERTIFICATION.md).

## Website

The website is explanatory. Compatibility is judged against `/spec` (especially `canonical.json`), not against marketing copy.
