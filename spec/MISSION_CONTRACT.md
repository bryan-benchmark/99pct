# Mission Contract

Every Mission answers these seven questions before admission. This is Missionism’s repository README — what makes Missions interoperable.

1. What world state are we trying to create?  
2. How will we know we’re getting closer?  
3. Who benefits?  
4. Who could be harmed?  
5. What do we currently believe drives the outcome?  
6. What evidence would make us change our minds?  
7. How is created value shared?  

Missions without a Contract are drafts, not Active Missions.

Consequential operating / era / equation decisions use the same [Decision Compiler](./DECISION_COMPILER.md) — gates, Triple-Win, Arrow Map, exposure, externalities, gaming, 10-year test — not a single magic score.
