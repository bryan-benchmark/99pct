## Bridge

Top down defines what “better” means. Bottom up discovers how to make it true.

Avoid: designing the perfect Mission Tree then forcing humans into it.  
Avoid: endless improvisation without a shared definition of value.

## Organizational rule

Every person should work as close to an independently measurable outcome as possible.

Not “I’m on Marketing.”  
Rather: “I own increasing qualified mission joins from 8% to 15%.”

## Synthesis

- **Bezos:** small autonomous teams + written reasoning + clear ownership  
- **Slicing Pie:** dynamic economic participation by contribution *(tool, not the whole system)*  
- **Missionism:** positive-sum equilibrium — Human ↑ · Company ↑ · Customer ↑ · Mission ↑  

## Operating loop

```
Parent Mission → Parent Equation → Local Equation → Constraint → Hypothesis
→ Decision Compiler (gates → Triple-Win → arrows → exposure → externalities → gaming → 10y)
→ Tiny Experiment → Proof → Learning → MCU attribution → Next Experiment
```

Every meaningful decision uses the same compiler — see `spec/DECISION_COMPILER.md`. AI asks for better trades; humans decide.

## Mission Cell

Tiny, autonomous, two-pizza team (normally 2–6; split by ~8).

### Roles

| Role | Owns |
|------|------|
| Mission Owner | The outcome |
| Builder(s) | Experiments |
| Verifier | Confirms Proof (not sole judge of own meaningful MCU awards) |

### Owns an outcome, not a roadmap

Better: increase first-session completion 42% → 75% while time-to-value stays under 10 minutes.  
Method unconstrained.

## Mission Contract (admission)

Before Active: answer the seven interoperability questions (world state, progress signal, beneficiaries, harm, drivers, falsifiers, value share). See `/mechanisms`.

## Mission Memo (1 page)

1. Parent · 2. Equation · 3. Current state · 4. Perfect state · 5. Constraint  
6. Hypothesis · 7. Experiment · 8. Proof · 9. Guardrails · 10. Reward  

Major strategy: 6-page memo, silent read, then discuss.

## Experiment clocks

1 day · 3 days · 1 week · occasionally 2 weeks.  
If you cannot learn within two weeks, slice again.

Lock before start: belief + optional prediction (baseline → target ± uncertainty).  
After: observed result. Explicit kill rule. Negative results can earn MCUs.

## Lineage · fork · sunset

Version equations and decisions (who proposed, evidence, vote, date). Serious model disagreement → fork; compete on results. Periodically: Continue / Redefine / Merge / Split / Accomplished / Terminate.

## Three Mine types

| Type | Proof | Reward |
|------|-------|--------|
| Outcome | Make X true (+ guardrails) | Net Mission outcome |
| Learning | Resolve whether X is true | Evidence quality |
| Unlock | Multi-node constraint removal | Often highest MCU |

## MCU at Cell level

Parent prices the Proof. Cell agrees split **before** work. Prospective changes only.

## Positive-Sum Search (disputes)

1. Understand (steelman)  
2. Shared parent Mission  
3. Conflicting variables  
4. Positive-Sum Search  
5. Experiment if empirical  
6. Explicit tradeoff  
7. Lowest competent decide  
8. Record + dissent  
9. Revisit when assumptions change  

For consequential proposals, run the [Decision Compiler](./spec/DECISION_COMPILER.md) first: hard gates, Triple-Win, Arrow Map, exposure, externalities, selfish-agent sim, 10-year test — then redesign so losers stop losing where possible.

## Mission Graph

UI shows parent / current / children. Underneath: dependencies, externalities, unlock opportunities (blocks / blocked by / unlocks). Unknowns are first-class: Known / Believed / Unknown → open Mines.

## Cadence

- **Friday 15-min closeout:** believed / tested / happened / learned / next → Mission Chain  
- **Quarterly:** reallocate toward true parent constraints  

## Benchmark lab equation

Optimize **Experience Leverage** (see `BUILD_PLAN.md`), not scenario-builder polish. Sorter / “Benchmark it” collapses expert effort while raising truth captured and reuse.

## Mission ↔ Enterprise (portfolio)

Organizations maintain **Mission Value** and **Enterprise Value** separately. Products declare a causal Mission bridge; score Mission / Enterprise / Option. Permanent **Mission Reinvestment** + **Disrupt Us** portfolio. Mine lanes: Enterprise · Mission · Bridge. See `docs/MISSION_ENTERPRISE_BRIDGE.md`.

## Useful ownership

Salary for today; Contributor Shares for decades; Capital Shares for outside capital that does not buy the mission. Founder Clock + continuous mining throttle. **Builder Leverage** (mission value / fully loaded resources) — not empire headcount. GoPrivate: QACY, 50/50 participation split (company choice), modular service/finance/ownership, three-key government — `spec/missions/GOPRIVATE_MISSIONISM_V0.1.md`, `spec/CONSTITUTIONAL_LAYERS.md`. Explainer: `docs/MISSIONISM.md`.

## Benchmark week-one (three Cells)

1. **Creator Speed** — reduce challenge creation time  
2. **Creator Success** — raise finish-useful-challenge rate  
3. **Distribution** — raise qualified people who try a Challenge  

Each: 2–3 people, one equation, one constraint, one experiment, one Proof, one small MCU pool, one Friday write-up. Then delete whatever felt bureaucratic.
